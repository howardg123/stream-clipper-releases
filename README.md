# Stream Clipper — downloads

This repository only holds the finished app. Go to **[Releases](../../releases/latest)** and download
`StreamClipper.exe`.

- Put it in a folder on a drive with about 20 GB free (for example `D:\StreamClipper\`) and double-click it.
- The first start downloads what it needs (Python, libraries, ffmpeg) into that folder. Nothing is installed
  system-wide.
- Already have it? The app tells you when a new version is out and installs it with **Update now**.

Each release also has `StreamClipper.exe.sha256`, the fingerprint the app checks before installing an update.
